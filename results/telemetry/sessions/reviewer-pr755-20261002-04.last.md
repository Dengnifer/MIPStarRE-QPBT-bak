## Review
The gate requires `row["path"]` to equal `.github/workflows/comparator.yml` exactly. GitHub’s documented workflow-run response uses a ref-qualified value such as `.github/workflows/build.yml@main`. Such a valid run is therefore treated as a decoy, leaving `official_seen=0` and blocking every live companion review. The tests conceal this by supplying the same bare path expected by the implementation. Accept and validate the documented ref-qualified form, then add a fixture using `.github/workflows/comparator.yml@<branch>`. ([docs.github.com](https://docs.github.com/en/rest/actions/workflow-runs?apiVersion=2022-11-28))

The five prior blockers are otherwise addressed: check/run/job binding is explicit, dispatch uses the primary instruction root, branch executables are not invoked, the full comparator configuration is fixed, and repository overrides are paired with validated local checkout identity.

Static verification passed for shell syntax, Python parsing, workflow checksum consistency, and `git diff --check`. I could not rerun the focused unit tests because the read-only sandbox provided no writable temporary directory; they failed before test setup.
